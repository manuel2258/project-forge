Universal list row: title, mono meta, latest event.

```jsx
<ListRow title="Replace the font atlas" meta={<StateLabel state="stuck">implementing</StateLabel>} latest="did_not_converge · 3 tests failing" latestTone="warning" edge="accent" />
```
Every row says what happened last, in words. Lists group under an Eyebrow; members of a source indent on a 1px rail.
